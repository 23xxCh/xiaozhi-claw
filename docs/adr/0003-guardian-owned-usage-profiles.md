# ADR 0003：监护人账户下的使用档案

- 状态：接受（家庭模式实现关闭）
- 日期：2026-08-13

## 决策

成人用户继续使用现有账户完成登录、认领和配置。每个成人账户迁移出一个成人使用档案。未来的 12–17 岁家庭模式使用监护人账户下的青少年档案，不创建青少年登录账户，不使用声纹，也不保存精确生日。

设备保存当前使用档案和当前智能体。网关只在新一轮 `listen.start` 时读取档案，因此切换不会改变正在进行的回复。家庭模式由服务端功能开关和账户白名单双重控制，默认关闭。

## 青少年默认策略

- 年龄段只允许 `12_13` 或 `14_17`。
- 记忆默认关闭；监护人同意后仍只保存可查看和删除的摘要与偏好。
- 安静时段为 22:00–07:00，每日限额 90 分钟，连续使用 30 分钟提醒。
- 家庭模式与当前云端均不开放摄像头上传。

## 后果

- 成人档案不受青少年时间策略影响。
- `Agent`、`Device` 与 `ConversationSession` 增加使用档案关联。
- 所有已有用户、设备、智能体、会话和记忆保留；迁移为已有成人账户补齐成人档案。
- 法律、安全和监护流程验收前，产品页面与协议继续按 18+ 公开。
