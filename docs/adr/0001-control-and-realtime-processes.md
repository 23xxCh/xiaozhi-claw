# ADR 0001：控制面与实时语音网关分进程

- 状态：接受
- 日期：2026-08-12

## 决策

控制面和实时语音网关使用同一 Python/FastAPI 代码仓库与同一 MySQL 数据库，但作为两个独立 ASGI 进程部署。首版不引入 Redis，不拆微服务。

## 原因

设备长连接、音频转码和模型流式调用不应阻塞用户及运营管理接口；同时首批设备数量不足以承担微服务、消息总线和多套部署流水线的成本。

## 后果

- 领域模型、认证、Provider 和审计代码可以复用。
- 进程间设备命令通过数据库 Outbox 传递。
- 进程内在线连接仅代表当前网关实例，控制面不得把内存连接表当作全局在线状态。
- 达到架构文档中的扩容门槛后，Outbox 可以替换为 Redis Streams，而不改变设备协议和控制台 API。
