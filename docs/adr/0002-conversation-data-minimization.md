# ADR 0002：对话数据最小化

- 状态：接受
- 日期：2026-08-12

## 决策

默认不保存原始音频和逐句对话全文，只保存会话元数据。只有用户主动开启智能体记忆后，系统才保存加密的摘要和偏好。

## 原因

设备面向成年消费者，但语音仍可能包含敏感信息。首版的个性化目标可以由用户可控的摘要记忆实现，无需长期保存完整语音和文本。

## 后果

- 历史页面展示会话时间、设备、智能体、轮数、延迟、成本和结束原因。
- 日志、审计和 Provider 用量记录禁止包含完整对话或音频。
- 用户可以查看、修改、导出和删除记忆；删除后密文不可再读取。
- 如未来需要逐句历史，必须新增独立同意、保留期限和删除机制，不得静默改变本决策。
