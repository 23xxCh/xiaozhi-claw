# ADR 0007：统一网页入口与逐台开箱状态

- 状态：接受；软件候选，不代表整机或零售放行。
- 日期：2026-09-07。

## 决策

日常配置以手机网页为主。公开 `/setup` 提供首次配网引导；`/setup?mode=wifi` 提供换网与恢复步骤。设备热点网页接收 Wi-Fi 密码，云端控制台只处理账户、认领、角色和已开放的设备参数。普通网页不能代替手机系统切换 Wi-Fi，也不能把用户点击“已完成”当作设备在线。

保留现有 FastAPI 控制面、实时网关、数据库 Outbox 和 Next.js。浏览器默认请求本站 `/v1/...`；正式环境由既有 OpenResty 转发，本地验证复用 Next.js 的 `CONTROL_API_PROXY_URL`。服务器地址不编进面向用户的浏览器代码，后端或地区变更不需要修改角色业务。正式入口沿用受控域名与 HTTPS 部署配置，本批次没有对外发布。

本地启动脚本自动选择唯一有默认网关的活动物理网卡，多个候选时要求显式选择。正在运行的服务遇到网络或模式变化时先拒绝并保留配置，避免文件已更新、旧进程仍在使用旧值。设备直接连接本地网关的试验方式仍需要正确的局域网地址；同源网页不等于设备也能自动发现更换网络后的电脑。

## 可观察契约

- `GET /v1/onboarding/status` 保留不传参数的兼容行为；可选 `device_id` 只允许当前账户名下设备，不存在或不属于账户均返回 404。在线状态、活动助手和首轮完成记录均针对该设备，其他设备的历史不能替它完成开箱。
- 配网、账户认领、设备在线、完成首轮对话是不同状态。角色和声音可稍后调整，不作为开始默认对话的必填步骤。
- 认领码通过二维码 fragment 或手工输入进入页面，不进入 URL query。认领成功后只暂存设备 ID；刷新必须重新向服务端核实当前归属。提交结果不确定时先查看设备，不自动重复提交。
- 两种 bootstrap 入口复用仍有效的设备绑定码，不延长原期限。码从随机 Claim ID 和设备 ID 进行有域前缀的密钥派生，数据库继续只保存校验哈希。旧随机码保留原有效期，成功认领、解绑和售后隔离清理该设备全部未消费码。
- 仅返回绑定码而没有 challenge 时，设备每 3 秒重查 bootstrap；同码只播报一次，网络错误恢复后重画二维码。CAM 与 NOCAM 在非单轮模式下均维护待机控制连接，在线仍以网关会话及心跳为准。
- 预连接期间不并发释放、替换或操作连接；关闭和重置在连接任务收尾后执行，取消的旧配置不得随后生效。过期令牌刷新复用现有 bootstrap 和 WebSocket，重连成功后丢弃旧连接排队的失败事件。设备配置回执与握手时的工具发现消息需保留至连接可用。
- 设备参数继续沿用 ADR 0005 的“已保存／等待确认／已生效／失败”；语音方案沿用 ADR 0006 的逐角色选择、音色兼容校验和下一轮生效。网页不接收用户填写供应商密钥。

## 设备服务地址边界

Hensun 身份产品的服务地址属于构建与发布配置。配网页隐藏该字段，设备 AP 服务端也拒绝提交 `ota_url`；既有 NVS 中的异源地址回退到受信编译地址，长期设备凭据发送前再次验证来源。显式本地 HTTP 验证构建仍可用，正式构建使用受控 HTTPS 地址。第三方组件的安全补丁从固定版本生成至构建目录，版本或锚点不匹配时阻断构建，禁止仅修改被忽略的依赖缓存。

## 尚需整机关闭的放行项

配网页关联成功早于 DHCP 和云端连接；目前仍依赖成功页发出退出 AP 请求。激活中或连接中的换网恢复、配网窗口控制、手机自动关闭门户后的恢复、错误密码与断网均需继续实现或真机验收。本批次引导明确保留页面并最终检查云端在线，不能将说明文字当成这些固件问题已修复。

豆包保持候选和关闭状态；国内成人开箱、两路线语音、长期运行、OTA 回退、备份恢复及运营验收按已有阶段门禁执行。海外采用独立区域服务和数据边界，目标国家未确定前不接入特定支付商或增加空适配器。
