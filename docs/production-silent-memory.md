# 第三批静默验收：记忆生命周期

日期：2026-09-09。设计见 [ADR 0008](adr/0008-memory-lifecycle.md)。本轮没有修改日常数据库、重启服务、调用真实语音模型、烧录或发布。

## 修复

过去清空账户记忆只删除已有数据，正在后台生成的摘要仍可能在完成后写回；关闭后迅速重新开启授权也有同类问题。已有摘要完成时的布尔授权检查不能识别这个变化。

新增独立memory_epoch及事务内条件写入，覆盖账户清空、偏好修改/删除、摘要修改/删除和角色授权变更；迟到任务作废。下一轮看到记忆版本变化会重建逻辑会话，清除旧短期问答，不要求设备重新连网。摘要开始和落库前检查设备仍归属原用户。
