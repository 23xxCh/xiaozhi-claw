# 手机配置与开箱流程：产品化候选记录

日期：2026-09-07。范围：本地软件候选和 NOCAM 构建；未作零售放行。

## 已交付

- 手机入口 `/setup`、换网恢复 `/setup?mode=wifi`，复用设备热点配网页。Wi-Fi 密码只提交到设备；浏览器仍需用户在手机系统中切换网络。
- 手工码与二维码统一进入 `/claim`。刷新检查账户归属，提交结果不明不自动再认领；错误、过期、离线、等待上线和首次对话分别显示。每台设备独立统计开箱进度，连接排序与设备页一致。
- 有效绑定码跨 bootstrap 重试保持不变，不顺延期限；旧码兼容，认领、解绑和售后隔离消费全部旧码。MySQL 发码事务使用局部 READ COMMITTED，避免新增设备的范围间隙锁；唯一冲突不锁其他设备的记录。
- 网页 API 默认同源 `/v1`，本地复用 Next.js 转发，正式环境复用已有 OpenResty。启动预检拒绝健康或启动中的旧进程被新配置覆盖，网络不再固定为某个私有 IP。
- Hensun 配网页不开放服务地址，AP 服务端拒绝写入该字段。发送设备长期凭据前校验编译地址来源；补丁从锁定版本的原组件生成，不改依赖缓存。
- 认领后的实机定位发现 NOCAM 被排除在待机预连接条件之外；已补齐 CAM/NOCAM 的自动连接。code-only 绑定每 3 秒重查且同码不重复播报。预连接与关闭/重置串行处理，保留 BOOT 原停止模式、配置回执和握手工具消息，短期令牌过期可刷新；旧连接排队的错误/关闭通知不能取消已恢复的连接。

架构决策见 [ADR 0007](../adr/0007-product-onboarding-and-same-origin-console.md)。原串联语音方案保留；豆包两个开放开关仍为 false。
