# 当前语音路线的公共音色目录

核对日期：2026-09-09。范围为项目已接入的 Qwen TTS 系列、火山 TTS 2.0、豆包 3.0 全双工；不是两家供应商所有历史产品的音色总表，不包含用户私有复刻音色。阿里托管应用保留应用默认入口；尚未实现的 Qwen-Audio 原生端到端不冒充可用方案。

## 覆盖与来源

- [阿里 Qwen TTS 官方表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)：实时表 48 个唯一音色，情绪实时模型兼容其中 24 个。保存每行准确模型版本列表，并合并同页批量 TTS 兼容模型，避免仅按供应商放行。
- [火山官方表](https://docs.volcengine.com/docs/6561/1257544?lang=zh)：第一表 293 个唯一音色（TTS 2.0 / S2S-O2.0 / 全双工）；第二表 151 个 TTS 2.0 外语音色。TTS 共 444 个；没有把第二表误算入全双工。
- 保留旧 jupiter VV，因此豆包目录记录数为 294（293 个当前表音色＋1 个旧兼容记录）。没有把两者误称为 294 个新官方音色。
- 全部目录共有 787 条供应商/音色记录：Qwen 48、火山 TTS 444、豆包 294、阿里应用 1。跨方案重复音色不是不同的声音。

火山数据从正常加载的官方网页读取；导入后对按原表顺序排列的 `voice|name` UTF-8 文本计算 FNV-1a 校验，与浏览器提取一致：第一表 `1182ed28`，外语表 `f092964e`。机器可读快照为 `backend/app/voice_catalog.json`，随 Python 包发布。

## 运行行为

- 新音色默认禁用，不覆盖已有开启/关闭状态、音色 ID、默认值或角色配置。
- `/v1/voice-library` 需成年账户登录，展示全部目录及兼容方案；原 `/v1/voice-presets` 继续只返回可选项。未开放音色即使绕过网页提交，也由服务端拒绝。
- 角色页“完整音色目录”支持当前方案、全部方案、供应商筛选及名称/编号/语言搜索，每批显示 50 条；标记当前方案可选、需换方案、未开放待验证。
- 当前本地 DB 已入库；保持 Qwen 12、火山 TTS 3、旧豆包 VV 1、阿里应用默认 1 条音色开启状态。豆包模型仍未开放，不能从音色 enabled 推断路线已可用。
- 本次没有逐个进行真实发声验证，也不宣称全部音色通过整机验收或商业使用授权核实。公共表含角色名称，收录不代表获得相关角色品牌/形象使用权。
