- 保留阿里 ASR、DeepSeek LLM、阿里 TTS、旧角色及音色。选定的三段模型真正绑定请求；增加独立豆包 S2S 适配器与角色语音方案选择，兼容音色和能力在网页及服务端校验。

- 豆包 JSON WSS、16k 输入 PCM/24k 输出 PCM、上行 Opus 流式解码、输出 Opus 编码/节奏控制、云端判停、提交去重、取消、ready/drained、工具白名单、未知费用与幂等已落地。
- 修复串联 TTS 因 token 分块截尾；首音前失败仅使用串联既有备用，丢弃未播放旧缓存再重试完整前缀，首包已发后不重播。固定提示也覆盖该规则。
- 解绑在同一事务内写撤权 Outbox；旧连接在空闲/对话中主动失效，旧撤权不影响新认领。修复同时到达的退出事件丢弃已收到 ping。
- 修复上行背压时失败通知无法解除写等待、取消等云端关闭才停止设备、FFmpeg 输出队列满时无法退出；保留真实 FFmpeg 满队列回归。
- G4 软件修复：每设备首次赠送一次并顺延账户有效期、旧库存保守防重、认领页显示真实在线、删除旧记忆存储、两个 OTA 查询入口遵循自动升级开关。
- NOCAM 启用严格播放 ACK 和阶段遥测；源码构建通过。GIF 显示不具备 CAM 的 PCM 口型绘制，明确声明 `pcm_mouth_sync=false`，此能力仍需后续实现/整机验收。
