## 验收输入与判据

全部使用虚构信息，不调用摄像头、不上传真实账户资料或历史记忆。

| 场景 | 测试设置 / 问题 | 判据 |
|---|---|---|
| 旧配置兼容 | 不传角色变量，问“你叫什么名字” | 原角色仍可回复，不念占位符 |
| 角色 A | 名称“测试青竹”，简短温和；问名字 | 与传入名称一致 |
| 角色 B | 名称“测试海石”，直接简洁；问名字 | 不继承 A 的名称或设定 |
| 音色 | A 用龙安欢，B 用龙安洋 | 两者均有完整音频，人工确认音色差异 |
| 语速 | 同一句固定测试文案，0.8 倍和 1.2 倍 | 参数接受、无截尾；比较同文案音频时长 |
| 授权记忆 | 虚构背景“测试用户的代号是银杏”；问代号 | 能使用所传背景 |
| 空记忆 | 独立身份与新 dialog，传空背景；再问代号 | 不泄漏上一角色背景，不编造答案 |
| 删除与关闭 | Hensun 删除或关闭后再次开启一轮 | 空记忆、新 epoch 身份、不续用旧 dialog |
| 网页生效 | 网页保存后开始下一轮 | 发出的参数与保存配置一致，当前轮不被中断 |
| 连续对话 | 两角色各三轮，再切换 | 无第二轮不回复、串音或错误继承 |

记录请求是否成功、转写、文本检查结论、音频字节数/时长和失败原因。供应商返回音频不等于真机扬声器已播放，真机实听另行记录。

## 放行限制
