# 工厂烧录与重新配网设计

## 目标

让内部装配人员用一个入口完成 Hensun 横屏设备的完整固件烧录、旧 Wi-Fi 清理和唯一设备身份写入；让使用者通过长按 BOOT 明确进入重新配网，并用一张简明说明卡完成配网和网站绑定。

## 接口设计

### 工厂烧录

- 输入：固件变体、Bootstrap URL、设备 SN、硬件版本、安全输入的设备密钥、经审核表情包及其 SHA-256、可选串口。
- 输出：已校验的完整固件、唯一身份、空白 Wi-Fi 配置和不含密钥的 JSON 质检清单。
- 保护：必须显式传入工厂重置确认；只接受 ESP32-S3、16MB 和固定分区地址；表情包必须匹配人工批准的 SHA-256；拒绝把设备身份打入通用固件包。

### 重新配网

- 输入：长按 BOOT 约 2 秒。
- 输出：停止当前会话并进入 `Xiaozhi-XXXX` SoftAP 配网模式。
- 兼容：BOOT 单击仍负责开始/停止对话；双击仍进入表情展示。

## 数据流

```text
构建固定变体
→ 校验六个工厂固件分区
→ 重新识别唯一 CH340
→ 写入并逐段校验固件
→ 清除通用 NVS 中的旧 Wi-Fi
→ 安全生成并写入唯一 hensun_keys
→ 输出 SHA256 质检清单

客户插电
→ 连接 Xiaozhi-XXXX
→ 192.168.4.1 写入 2.4GHz Wi-Fi
→ 屏幕显示 6 位绑定码
→ 网站邮箱登录并绑定
```
