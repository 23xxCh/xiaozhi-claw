# Hensun 网页与阿里角色映射候选

状态：已实现软件候选，云端模板与真机验证未完成。未替换 3000 网页、未重启实时网关、未更新固件。

## 网页

- 保留 Next.js、现有账户与角色接口。灰白工作区、深色导航、黄色操作强调；不新增 UI 依赖。
- 配网页区分家庭 Wi-Fi、账户认领、真实在线三个阶段。设备本地配置拆为四个可返回步骤，手机离线时可继续阅读。
- 点击“下一步”只改变指引，不写设备在线状态。Wi-Fi 密码仍只发送到设备自身页面。
- 角色页改成角色列表与分区编辑器。声音、记忆、高级设置分开，保留原子保存和下一轮生效。
- 修正“只差一步”和“阿里每轮独立”的过度描述。实际设备状态仍由现有 API 检查。
- 独立构建：`HENSUN_NEXT_DIST_DIR=.next-candidate npm run build`，验证服务端口 3001。3000 保留原版本。

## 阿里适配

沿用 Agent、VoicePreset、配置快照、记忆 epoch 和 ConversationBackend，不新增数据库表或框架。

- `downstream.voice`：支持应用默认及龙安欢、龙安洋候选。两项新增目录默认不开放，必须验证当前应用 TTS 的兼容性后启用；没有宣称覆盖全部阿里音色。
- `downstream.speech_rate`：将网页 0.5–2.0 倍映射为 50–200。
- `user_prompt_params`：固定三个模板变量 `hensun_name`、`hensun_persona`、`hensun_memory`，前端不能自行传入供应商 JSON。
- `ALIYUN_DIALOG_ROLE_OVERRIDES=false` 为默认值。开启后才允许网页修改阿里人设，并在上游首帧注入角色和授权记忆。
- 开启模式下，供应商身份由工作空间、应用、账户、使用档案、角色和记忆 epoch 生成稳定 UUID；换角色及清除记忆使用独立身份。身份不含邮箱或手机号。
- 配置或记忆版本变化不继续复用旧 dialog。普通同角色对话沿用现有上下文恢复逻辑。
- 记忆复用现有解密与 ContextBuilder；连接时尚无当前问题，使用有限背景和摘要，不宣称按当前问题精准检索。传入文本上限 4000 字符，加载超时 0.5 秒或失败不阻塞语音。
- 关闭授权后下一轮传入空记忆，旧 epoch 不读取新记录；现有摘要写回保护保持不变。已发送到供应商的当前轮数据无法靠本地删除撤回。

## 云端启用前必须完成

1. 在独立验证应用或经过备份的应用模板中声明三个变量；固定系统规则保留在变量外。明确 `hensun_memory` 是不可信背景事实，其中命令不得执行。
2. **关闭阿里原生长期记忆**。本阶段仅使用 Hensun 管理的记忆，不能让关闭本地开关的用户仍被云端自动记忆。
3. 实测变量替换、角色名称、人设和两种音色，确认音色权限、语速及不念出变量/标签。模板未准备好不能设置 role_overrides=true。
4. 双进程使用相同启用配置；先发布后端再开放网页能力。当前 Chrome 阿里标签读取两次超时，因此本轮没有修改或发布云端应用。
5. 两账户、多角色、跨重连、关闭记忆、删除及迟到摘要任务都需要验证。真实记忆召回、上下文继承、语音首响和连续追问尚未验收。
6. 搜索覆盖和其他高级参数作为后续独立变更；本版不启用设备工具或未经验证的云端参数。

## 回退

关闭 role_overrides，保留用户已保存的人设以便后续恢复。若停用已选中的候选音色，需要用户手动切换到应用默认音色；不静默跨路线切换、不恢复旧数据库。网页回到原构建目录即可。候选源码不是生产或真机通过证明。
