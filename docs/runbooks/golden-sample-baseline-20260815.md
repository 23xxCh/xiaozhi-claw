- 板型：`hensun-cam-pilot-v1`
- 产品变体：横屏自有网关版

- 串口：CH340 `COM6`（端口可能随电脑变化，不作为设备身份）
- ESP-IDF：6.0.2
- 应用分区烧录地址：`0x20000`
- 表情资源分区烧录地址：`0xB00000`

## 恢复边界

恢复应用时只写入 `0x20000`，恢复表情时只写入 `0xB00000`。除非另有书面操作单，不得擦除整片 Flash，也不得覆盖 NVS、`hensun_keys`、语音模型资源或 Wi-Fi/设备身份。

Bootstrap 地址和模型密钥不记录在本文件或 Git 中，继续通过本机未提交配置及构建参数注入。
