- 1000 个空闲 WSS 连接持续 2 小时。

- 任一 ASR、LLM、TTS 服务超时都有稳定错误码、指标和已演练的降级路径。
- 数据库、日志和 OSS 抽检不到原始音频、逐句 STT、逐句回复或密钥。
