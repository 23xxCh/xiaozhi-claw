# 小灿桌面助手｜熟人内测使用卡

> 仅供 18 岁以上熟人内部测试。当前使用 Staging 测试环境，不是正式销售产品。

## 收到后只做四步

1. **插电**：使用随附的 5V USB-C 电源和线，等待屏幕出现配网提示。
2. **手机配网**：手机连接 `Xiaozhi-XXXX`；自动页面未弹出时，在浏览器打开 `http://192.168.4.1`。选择家里的 **2.4GHz Wi-Fi**，输入密码并保存。
3. **登录并绑定**：扫描设备屏幕上的绑定二维码，用你自己的邮箱验证码登录并确认 18+ 与内测协议。登录后会自动继续绑定，不用重新扫码；扫码失败时才在“设备”页输入屏幕上的 6 位备用码。
4. **直接聊天**：网站显示“在线，可以聊天”后，对设备说：**“你好小灿”**。

助手名称、性格和音色都可以以后再改，不影响第一次聊天。

设备二维码采用 `https://staging.hensun-desk.top/claim#code=123456` 形式；实际数字每次不同，10 分钟后失效。`#code` 位于浏览器 fragment，不会随网页请求进入服务器访问日志。

## 遇到问题

- 手机提示“此网络无法上网”：选择“仍然连接”，不要切回移动网络。
- 看不到家里的 Wi-Fi：确认路由器已开启 2.4GHz；只有 5GHz 时，可临时使用开启 2.4GHz 兼容模式的手机热点。
- 找不到 `Xiaozhi-XXXX` 或需要更换 Wi-Fi：设备通电后，**长按 BOOT 约 2 秒**，等配网热点重新出现，再重复第 2 步。
- 绑定二维码或备用码过期：让设备重新联网，以屏幕新显示的二维码和 6 位备用码为准。
- 已被其他账户绑定或联网后仍无回复：联系内部测试负责人，不要刷机或拆机。
